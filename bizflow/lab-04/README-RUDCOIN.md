# Lab 04 — формы и Twig в RUD COIN

Предметная область: цифровой профиль студента программы RUD COIN. Форма Symfony Form содержит имя, университетскую почту, факультет, направление подготовки и описание интересов. Валидация реализована Symfony Validator. Успешное сохранение помещает данные в сессию; база данных в этой лабораторной не используется. CSRF включён стандартным механизмом Symfony Forms.
