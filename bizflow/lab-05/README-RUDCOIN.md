# Lab 05 — RUD COIN и Doctrine ORM

Модель предметной области: Student (студент), Wallet (кошелёк), CoinTransaction (начисление/списание RDC), UniversityEvent (мероприятие с размером возможного вознаграждения), Privilege (привилегия и её стоимость). Баланс кошелька хранится целым числом RDC; метод Wallet::apply проверяет тип операции, положительную сумму и достаточность баланса перед списанием.

Панель `/` получает агрегаты и последние операции из Doctrine. Миграция `Version20261122120000` создаёт таблицы и внешние ключи. Fixtures содержат только демонстрационные данные. Для запуска нужны MySQL и PDO MySQL; миграции и fixtures следует выполнять только после настройки DATABASE_URL.
