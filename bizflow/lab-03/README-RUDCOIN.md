# Lab 03 — RUD COIN на Symfony

Проект сохраняет Symfony 7.4, маршрутизацию через атрибуты контроллеров и Twig-шаблоны. BizFlow заменён на предметную область RUD COIN: главная страница концепции, описание проекта и демонстрационный кошелёк.

Маршруты: `/`, `/about`, `/dashboard`. Баланс и операции на dashboard демонстрационные и передаются контроллером; постоянного хранения на этом этапе нет.
