# AI log — лабораторная работа №1

## Запрос ИИ-аналитику
Ты — архитектор PHP-приложений. Предложи минимальную архитектуру учебного PHP 8.2+ приложения без фреймворка с Composer, PSR-4 и front controller. Контроллер не должен содержать бизнес-логику; расчет стоимости должен тестироваться отдельно.

## Архитектурное решение
- `public/index.php` — единая точка входа и таблица маршрутизации.
- `src/Http/Request.php`, `Response.php` — получение HTTP-запроса и отправка ответа.
- `src/Controller/QuoteController.php` — преобразование входных параметров в вызов сервиса и HTML-ответ.
- `src/Domain/Money.php`, `Quote.php` — денежная сущность в целых копейках и результат расчета.
- `src/Service/QuoteCalculator.php` — бизнес-правила расчета без зависимости от HTTP.
- `tests/QuoteCalculatorTest.php` — unit-тесты калькулятора.

## Запрос ИИ-тестировщику
Проанализируй QuoteCalculator. Создай unit-тесты обычных и граничных значений, ошибочных значений и округления денежных сумм. Не меняй ожидаемый результат ради зеленого теста.

## Принятые правила
- Количество и цена должны быть больше нуля.
- Скидка должна быть в диапазоне 0–50 процентов.
- Деньги хранятся в целых копейках.
- Сумма скидки округляется до копейки по правилу half-up.
- Некорректные параметры дают HTTP 400; неизвестный путь — 404; неожиданный сбой — 500.

## Самопроверка перед сдачей
Выполнить `composer validate`, `composer dump-autoload`, `vendor/bin/phpunit`, проверить маршруты через `curl -i`. Фактический результат выполнения команд студент фиксирует после установки Composer и PHPUnit в своей среде.
