# PHP Web Course — комплект лабораторных

## Структура
- `plain-php/` — лабораторная №1.
- `bizflow/lab-02` … `bizflow/lab-05/` — отдельные снимки BizFlow для лабораторных №2–5.
- `framework-comparison/` — сравнительный анализ.
- `deploy/` — материалы развёртывания.
- `docs/ai/` — журналы работ №1–12 и итоговая проверка.
- `docs/security/`, `docs/deployment/` — общие требования.

## Важно
В исходном наборе были доступны ZIP-архивы лабораторных №1–5. Лабораторные №6–12 представлены только шаблонами журналов: их исходные задания и код не предоставлялись. Локальный `.env.test` из архива №3 исключён при переносе.

## Git-теги
После импорта запустите `push-to-github.sh` (Linux/macOS/Git Bash) или `push-to-github.ps1` (Windows PowerShell). Скрипты создают последовательные коммиты и теги `lab-01` … `lab-12`, затем отправляют ветку и теги в GitHub.
