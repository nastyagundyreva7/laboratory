# Лабораторная работа №5 — Doctrine ORM

Источник: комплект lab-05-doctrine. Включает сущности Customer, Product, SalesOrder, OrderItem, связи, миграцию, fixtures, QueryBuilder-отчёты и тесты. Денежные суммы хранятся целыми числами; unitPriceCents сохраняет историческую цену позиции. Выполнить schema:validate, migrations:status и PHPUnit на локальной MySQL-БД.
