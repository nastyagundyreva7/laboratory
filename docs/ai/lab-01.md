# Лабораторная работа №1 — Plain PHP

Источник: комплект plain-php. Архитектура: front controller, PSR-4/Composer, HTTP Request/Response, Domain Money/Quote, QuoteCalculator и unit-тесты. Правила: сумма в копейках, скидка 0–50%, округление half-up. Самостоятельно выполнить composer validate, dump-autoload, PHPUnit и curl-проверки; записать фактический результат.
