# Лабораторная работа №3 — PHP и Symfony

Снимок проекта Symfony с маршрутизацией, контроллерами, сервисами, шаблоном Twig и тестами. Файл локальной среды .env.test намеренно исключён; создайте локальные настройки из документации проекта. Выполнить composer install, bin/console about, debug:router и PHPUnit.
