# Безопасность

- Не хранить секреты в Git; локальные значения размещать в .env.local.
- В репозитории держать только безопасный .env.example.
- Для SQL использовать prepared statements; динамические идентификаторы выбирать из whitelist.
- Валидировать входные данные на сервере.
- Экранировать пользовательский вывод в Twig; не использовать |raw для недоверенного контента.
- Использовать CSRF-защиту для форм.
- Не запускать интеграционные тесты на рабочей базе.
- Проверять зависимости и конфигурацию перед публикацией.
