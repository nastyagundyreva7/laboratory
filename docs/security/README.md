# Безопасность

- Не коммитить `.env`, `.env.local`, `.env.test` с секретами и ключи доступа.
- Использовать `.env.example` только с демонстрационными значениями.
- Для SQL использовать prepared statements; динамические имена полей и сортировки проверять по allowlist.
- Валидировать данные на сервере; включать CSRF-защиту форм.
- Экранировать пользовательский вывод в Twig; не использовать `|raw` для недоверенных данных.
- Использовать отдельную тестовую БД.
