# Выбор PHP-фреймворка

В лабораторных №3–5 используется Symfony. Снимки проектов сохранены отдельно в `bizflow/lab-03`, `bizflow/lab-04` и `bizflow/lab-05`, чтобы последующие работы не перезаписывали предыдущие.

При сравнении фреймворков оценивайте маршрутизацию, DI, ORM, шаблоны, валидацию, безопасность, тестирование, документацию API, поддержку и стоимость сопровождения. Вывод о выборе должен опираться на требования учебного проекта и проверенные версии зависимостей.
