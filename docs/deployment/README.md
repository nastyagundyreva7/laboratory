# Развёртывание

Production-процесс зависит от конкретного проекта. Базовые проверки: установить зависимости Composer, вынести секреты в переменные окружения, выполнить миграции контролируемым способом, настроить document root на `public/`, отключить debug, включить HTTPS и проверить логи. Для Symfony проверить production cache и права на `var/`.
